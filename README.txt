VOLTARA WEBSITE
================
Open index.html in a browser to view the site.

Files:
- index.html — complete responsive website
- style.css — visual styling and responsive layout
- script.js — mobile navigation, flavour selection, demo cart interaction
- assets/voltara-campaign.png — campaign artwork generated for this concept

This is a fictional/concept drink brand. Product claims, pricing, ingredients and benefits are creative mockup content and should be verified/replaced before real commercial use.
